# Welcome to Nukleio

Nukleio is a platform for managing the content that powers your portfolio website from a single location.

Instead of hardcoding project information, experience, education, resumes, images, and other portfolio data directly into your website, Nukleio stores everything in one centralized backend and exposes it through a simple API. Your portfolio becomes a client that consumes this data, allowing updates to appear immediately without modifying or redeploying your website.

---

## Why Nukleio?

Keeping a portfolio up to date is often tedious:

- Every change requires editing source code.
- Multiple portfolio sites must each be updated individually.
- Images and documents have to be manually replaced.
- APIs and backend services need to be recreated for every new project.

Nukleio solves this by separating your **content** from your **presentation**.

Update your information once, and every connected portfolio can immediately access the latest version.

---

## Core Features

- 🚀 Centralized portfolio management
- 📂 File storage for resumes, transcripts, portraits, and project images
- 🔐 Secure authentication with Supabase
- 🌐 Public API for portfolio integrations
- 💳 Stripe payment support
- 🤖 AI-powered features (coming soon)
- ⚡ Built with Next.js and Supabase
- 📈 Designed for scalability and performance

---

## Architecture

At a high level, Nukleio consists of four components:

```text
Portfolio Website
        │
        ▼
  Nukleio Public API
        │
        ▼
 Next.js Backend
        │
        ▼
    Supabase
(Database + Auth + Storage)
```

Your portfolio never needs direct database access. Instead, it communicates with the public API, which securely retrieves the appropriate data from Supabase.

---

## Who is Nukleio for?

Nukleio is designed for developers who:

- maintain one or more portfolio websites
- want to separate content from frontend code
- want a reusable backend across multiple portfolio projects
- prefer managing portfolio data through an intuitive dashboard instead of editing source files
