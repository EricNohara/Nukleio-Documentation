# Pricing

Nukleio plans are designed around how much portfolio infrastructure and job-search automation you need.

The billing dashboard supports monthly and yearly plan options. Current product tiers are Free, Developer, and Premium.

## Plan Summary

| Plan      | Best for                                                             | Current price                  |
| --------- | -------------------------------------------------------------------- | ------------------------------ |
| Free      | Small portfolios and first-time users                                | $0                             |
| Developer | Software developers who want more API capacity and portfolio tooling | $0.99 monthly or $10.99 yearly |
| Premium   | Active job seekers who want unlimited AI usage                       | $4.99 monthly or $54.99 yearly |

Prices shown here reflect the current Nukleio app configuration. Check the billing page in your account for the latest checkout details before subscribing.

## Free Plan

The Free plan is the default plan for small portfolios. Choose Free if you are setting up Nukleio for the first time or connecting one basic portfolio site.

## Developer Plan

The Developer plan is designed for software developers who want more room to experiment. Choose Developer if you maintain multiple portfolio versions, want separate keys for production and testing, or expect to use Nukleio as part of an ongoing portfolio workflow.

## Premium Plan

The Premium plan is designed for active job seekers and power users. Premium unlocks the strongest job-search workflow because it supports heavy use of Nukleio's AI features, including resume generation, cover letter generation and revision, and professional headshot generation.

## Choosing a Plan

Use this quick guide:

| If you need...                                      | Choose... |
| --------------------------------------------------- | --------- |
| One API key for a small portfolio                   | Free      |
| Multiple API keys for portfolio variants or testing | Developer |
| Portfolio tooling without heavy AI usage            | Developer |
| Unlimited API keys and frequent AI generation       | Premium   |
| AI cover letter workflows for active applications   | Premium   |

## Managing Billing

From the billing area in Nukleio, you can:

- view your current plan
- switch between monthly and yearly billing intervals
- start checkout for Developer or Premium
- open the billing portal
- manage subscription changes

If you change plans, refresh your dashboard after checkout or portal changes so Nukleio can update your current tier.

## AI Usage and Plan Access

Some AI features are plan-gated. For example, premium access is required for the full cover letter workflow in the current app.

AI features include:

- resume generation from Nukleio data
- AI-enhanced resume generation for target job types
- cover letter generation, scoring, caching, revision, and PDF preview
- professional headshot generation and revision

If an AI feature is unavailable, check your current plan in the billing dashboard.
