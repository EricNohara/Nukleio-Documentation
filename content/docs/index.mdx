# Docs

These docs explain how to use Nukleio as a customer: manage portfolio content, connect a portfolio website, use API keys, understand the public API, and troubleshoot common issues.

If you are new to Nukleio, follow the guides in order.

## Start Here

1. [Getting Started](./getting-started)
2. [Account and Dashboard Overview](./account-dashboard-overview)
3. [Managing Profile Information](./managing-profile-information)
4. [Managing Projects](./managing-projects)
5. [Uploading Files and Images](./uploading-files-and-images)

These pages help you prepare the content your portfolio will use.

## Connect Your Portfolio

Once your account has content, use these guides to connect a site.

1. [Creating API Keys](./creating-api-keys)
2. [Connecting a Portfolio Website](./connecting-a-portfolio-website)
3. [Public API Reference](./public-api-reference)

These pages explain how your portfolio requests Nukleio data and how to handle the API response.

## Fix Issues

Use [Troubleshooting](./troubleshooting) when something does not work as expected.

Common topics include:

- updated content not appearing on a portfolio
- invalid or missing API keys
- upload issues
- portfolio caching
- deployment environment variables
- empty dashboard analytics

## Product and Pricing

For a broader overview of what Nukleio includes, read [Product](../product).

For plan features and billing guidance, read [Pricing](../pricing).

## What These Docs Are Not

These docs are not a guide for self-hosting Nukleio or deploying your own copy of the Nukleio application.

They are written for customers and users who want to understand the hosted product, manage their portfolio content, and connect their own portfolio websites to Nukleio.
