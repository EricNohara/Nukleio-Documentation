# Dashboard Overview

The Nukleio dashboard is your main workspace for managing portfolio content and monitoring how connected portfolio sites use your data.

After you sign in, the dashboard gives you access to the tools you need to update profile details, maintain projects, upload portfolio assets, manage API keys, and review public API activity.

## Home Dashboard

The home dashboard gives you a quick view of how your connected portfolio integrations are performing.

It includes views such as:

- **Recent API activity** — Review the latest requests made through connected portfolio websites and integrations.
- **Request success and failure counts** — Compare successful and failed requests to identify problems quickly.
- **Recent latency distribution** — Monitor response times and spot unusually slow API requests.
- **Top connections by API key** — See which integrations and API keys are generating the most traffic.
- **Overall availability** — Check the current health and availability of your API services.

Use this area to check whether your portfolio integrations are successfully reaching Nukleio. If a connected site stops updating, starts returning errors, or uses an old API key, the dashboard activity views can help you spot the issue.

The user's dashboard will look different depending on their membership plan. Free plan users can view their performance stats for the past week. Developer plan users can view their stats for the past 2 weeks. Premium users can view their stats for the past month.

## Public API Activity

When a connected portfolio requests data from Nukleio, the request can appear in dashboard analytics.

These views help answer questions such as:

- Is my portfolio successfully requesting data?
- Which API key is being used most often?
- Are requests failing?
- Has latency changed recently?
- Did traffic spike after a portfolio update?

## API Keys

API keys allow portfolio websites to request your public Nukleio data.

Use API keys to connect to one portfolio site only. Give each key a clear description so you can identify it later in activity charts and logs. If there are any visible issues in your dashboard, you can navigate to a given API key by clicking on one of the charts in the dashboard.

You can set an expiration date on a key for maximum security. Keys can be refreshed at any time. If you no longer use an integration, it is suggested that you delete its associated API key.
