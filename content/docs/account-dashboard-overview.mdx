# Account and Dashboard Overview

The Nukleio dashboard is your main workspace for managing portfolio content and monitoring how connected portfolio sites use your data.

After you sign in, the dashboard gives you access to the tools you need to update profile details, maintain projects, upload portfolio assets, manage API keys, and review public API activity.

## Home Dashboard

The home dashboard gives you a quick view of how your connected portfolio integrations are performing.

It may include views such as:

- recent API activity
- request success and failure counts
- recent latency distribution
- top connections by API key
- overall availability

Use this area to check whether your portfolio integrations are successfully reaching Nukleio. If a connected site stops updating, starts returning errors, or uses an old API key, the dashboard activity views can help you spot the issue.

## Profile and Settings

Your profile and settings area contains the personal information your portfolio can display.

This includes details such as:

- name
- email address
- phone number
- current role
- current company
- location or address
- bio
- social and professional links

This is usually the first area to complete because many portfolio sections depend on profile data.

## Projects

The projects area is where you manage the portfolio items you want visitors to see.

A project can include:

- name
- date range
- description
- GitHub URL
- demo URL
- programming languages
- frameworks
- technologies
- thumbnail image

Use consistent formatting across projects so your connected portfolio can render clean project cards, project pages, or project galleries.

## Files and Images

Nukleio can store portfolio assets that your website needs to reference.

Common assets include:

- portrait or profile image
- resume
- transcript
- project thumbnails

The upload interface supports selecting files from your computer or dragging and dropping files into the upload area. Image files can be previewed before saving, and PDFs can be previewed when supported by the browser.

## API Keys

API keys allow portfolio websites to request your public Nukleio data.

Use API keys to connect one or more portfolio sites. Give each key a clear description so you can identify it later in activity charts and logs.

Good API key descriptions include:

- Personal Portfolio
- Main Portfolio Site
- Portfolio Redesign
- Local Testing
- Resume Website

If you no longer use an integration, remove or rotate the related key.

## Public API Activity

When a connected portfolio requests data from Nukleio, the request can appear in dashboard analytics.

These views help answer questions such as:

- Is my portfolio successfully requesting data?
- Which API key is being used most often?
- Are requests failing?
- Has latency changed recently?
- Did traffic spike after a portfolio update?

If something looks wrong, use the troubleshooting page to narrow down whether the issue is an API key, request header, deployment cache, network issue, or portfolio rendering problem.

## Recommended First Pass

When setting up a new account, move through the dashboard in this order:

1. Complete your profile.
2. Upload your core files and images.
3. Add at least one project.
4. Create an API key.
5. Connect your portfolio site.
6. Confirm API activity appears after your portfolio requests data.

This gives you enough content to test a real portfolio integration without needing to complete every optional field first.
